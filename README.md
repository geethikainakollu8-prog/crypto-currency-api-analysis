# Cryptocurrency Market Analysis Using CoinGecko API

## Project Overview

This project analyzes real-time cryptocurrency market data using the CoinGecko API. The data is collected using Python, processed with Pandas, and visualized using Matplotlib.

## Tools Used

* Python
* Requests
* Pandas
* Matplotlib
* CoinGecko API
* GitHub

## Project Workflow

1. Extract cryptocurrency data from CoinGecko API
2. Convert JSON data into a Pandas DataFrame
3. Select relevant features
4. Save data into CSV format
5. Perform Exploratory Data Analysis (EDA)
6. Generate business insights
7. Create visualizations

## Dataset Features

* Name
* Symbol
* Current Price
* Market Cap
* Total Volume
* Price Change Percentage (24h)

## Key Findings

### Highest Market Cap

Bitcoin had the highest market capitalization among all analyzed cryptocurrencies.

### Highest Trading Volume

Tether recorded the highest trading activity.

### Top Gainer

Figure Heloc achieved the highest positive price change in the last 24 hours.

### Biggest Loser

Zcash experienced the largest decline in price during the last 24 hours.
